📋 Quick Guide

Getting Started

  • 🔧 Use the toolbar to select gates and inputs for your circuit
  • ➕ Click on a gate to add it to the canvas
  • 🗑️ Right-click on a gate to remove it

Connecting Gates

  • 🔗 Gates can be dragged and connected to each other
  • 🟡 Click the connector tool (turns yellow when active)
  • 🔴 Click input/output circles to create connections

Controls

  • 🔄 Use the reset button to clear the canvas
📱 Screen Size Notice
This simulator requires a larger screen for the best experience. Please use a desktop or tablet.
